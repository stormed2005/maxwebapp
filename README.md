# MAX Mini App «Какой ты сквиш?»

Проект полностью работает на Netlify, Python не нужен.

1. Загрузите эту папку на GitHub и подключите репозиторий в Netlify.
2. В Netlify откройте **Site configuration → Environment variables** и добавьте `MAX_BOT_TOKEN` и `MAX_CHANNEL_ID`.
3. После публикации вставьте выданный Netlify адрес (`https://...netlify.app`) в настройках Mini App MAX.

Без переменных токена приложение работает в демо-режиме. Эмодзи в `app/app.js` можно заменить на свои изображения.
